## 1.2 功能

入口：设置 → 通用设置 → 玻璃美化 · Ash。主界面遮罩不透明度独立于顶部栏、输入栏及气泡（均0–100%）；主界面0%显示清晰原图，不淡化文字。气泡纵向内边距缩为5px，压缩段落首尾空白；最大宽度60–100%可调。AI和用户头像位置各自可选侧边或上方，上方释放完整横向消息空间。

保留双方气泡与字体HEX色号、界面文字色、侧边栏和设置页独立图片背景、模糊、圆角、CSS编辑导入与恢复默认。自定义CSS在设置路由和全屏设置弹层不加载。图片压缩后保存在本地图片存储。

消息分割默认关闭，模式可选段落/换行及顶层列表项/普通文字逐句；生成结束后只改变显示，不改存储消息和上下文。围栏/缩进代码、数学块、表格、引用、嵌套列表保留其渲染范围；引用链接/脚注/HTML不拆。复制、编辑、重试仍按原消息处理。

## 手机 MCP

开放设置MCP入口及手机版工作模式，原生HTTP适配Streamable HTTP，支持自定义请求头/Bearer。可连接HTTPS远程服务以及localhost/127.0.0.1上的Termux HTTP服务；本机明文HTTP由configure_android.py生成专用网络配置。非本机远程地址使用HTTPS。

支持获取工具列表、刷新和调用，工具接入原有生成链路。连接后在新对话中选支持工具的模型并开启工作模式。没有开放桌面代码执行、本地stdio、传统长连接SSE及浏览器OAuth回调；stdio需由Termux服务转换为HTTP。可选GET通知流返回405，有限POST SSE响应可处理。配置和请求头不写入控制台调试日志。

## 构建与签名

工作流执行显示/设置/原生网络适配/MCP控制器/工具模式测试，再构建前端和Android APK。configure_android.py设置versionCode=3/versionName=1.2。

CI原始debug APK仍使用临时签名，不可直接覆盖手机当前版。交付前重新使用私有ash-glass-test-signing.p12，alias ashglass-test；固定证书SHA256 12ac55c7305748683102b4f9ca4159a4f204628aaa86f933191c67e9e1662d46。签名文件不提交到GitHub；同签名覆盖更新保留配置和聊天，勿卸载。

初次跨签名迁移已备份恢复；旧加密偏好与卸载后Android Keystore不匹配可能导致SQLite插件启动失败，仅需备份并重建sqlite_encrypted_shared_prefs.xml，业务数据库为no-encryption，不应删除。正常同签名更新无需此操作。

具体测试和真机验收状态以对应工作流、交付记录为准，打包完成不等于所有MCP服务已验证兼容。


## 1.4.5：输入栏清透与设置顶部背景

输入栏与顶栏的模糊随各自不透明度缩放，0%同时去掉底色、滤镜、阴影及可见边框，文字/按钮保留。暂停操作栏使用相同输入区材质。设置路由及全屏设置模态单独使用内置玻璃样式，设置背景覆盖App安全区域与标题栏，内容层不重复铺背景；仍不加载用户自定义CSS。聊天和设置顶栏共用顶部栏透明度。关闭玻璃时恢复普通主题。
